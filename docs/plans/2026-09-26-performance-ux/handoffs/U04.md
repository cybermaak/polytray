# U04 handoff: keyboard navigation and focus

## Implementation

- Added stable-key roving focus to the virtualized file grid. Arrow keys use rendered CSS column count; Home/End use the loaded range; PageUp/PageDown use the visible page. `VirtuosoGrid.scrollToIndex` and a bounded render/focus retry move focus to unmounted cards.
- Vertical page-edge requests preserve the requested column and focus the matching stable key after the next page arrives. Refreshes retain focus by key, fall back to the nearest surviving item after removal, and ignore metadata-only refreshes when the key sequence is unchanged. When that logical key is virtualized out of the DOM, the first rendered card temporarily provides the grid tab stop without replacing the logical key.
- Regular files support Enter to preview, Space to preview outside multi-select, and Space to toggle selection in multi-select. Archive summary cards have no selection control and remain preview/navigation targets. Existing modifier-click and drag handling was left intact.
- Added named card/selection controls, pressed/selected/current states, visible keyboard outlines, and coalesced result/selection status announcements. Each card's selection button remains pointer-operable but is excluded from sequential Tab stops. `Shift+Enter` toggles the focused file to start batch selection; after a selection exists, Space toggles the focused file. Ordinary Enter and Space preview when multi-select is inactive. The grid description documents this path.
- Folder navigation now exposes a named tree with roving focus, Up/Down/Home/End movement, Left collapse/parent movement, Right expansion/child movement, and selected/expanded states. Nested treeitems are inside `role=group`. Library root removal stays available by pointer through the existing control and by Delete on the focused root treeitem; the hint and `aria-keyshortcuts` document the action, and the control is not an extra Tab stop. Sidebar Add Folder, theme, and Settings buttons remain independently keyboard reachable. Focus remains on a selected nested folder.
- Closing compare restores focus to its invoking control. If a selected item has been virtualized out, the rendered grid fallback provides an available tab stop while preserving the logical focus key.
- Added a shared topmost overlay focus manager. Settings and narrow/expanded preview contain Tab focus, consume Escape only when topmost, and restore focus to their invoking element when available. Docked preview stays nonmodal. PreviewPanel already exposed `onClose`; App records/restores the invoking element without changing the callback API or preview geometry/state behavior.
