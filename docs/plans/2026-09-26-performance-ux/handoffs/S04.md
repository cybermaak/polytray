## Measurement contract

`src/shared/model/measurement.ts` defines version 1 measurements with `unit`, `basis: "source-build"`, and explicit `status`. Available values require finite nonnegative x/y/z; unavailable values have null axes and a reason. STL and OBJ results use `model-unit`; 3MF results use `mm`. Zero thickness is preserved. `toMeasurementPresentation` is a pure U06-facing adapter and treats legacy bare x/y/z JSON as unverified.

`src/shared/model/fast3mfGeometry.ts` is the former renderer fast parser moved into a DOM-free shared module. `src/renderer/lib/fast3mfPreviewParser.ts` remains a compatibility re-export so the existing preview path and tests continue to use the same parser. The parser's prior fast-path eligibility checks remain, and stricter malformed-coordinate, index, missing-object, and transform errors cause measurement unavailability / fast-path fallback rather than invented dimensions. Source-build bounds are computed from instantiated build items, after nested component and build-item transforms and before display transforms. Unused resources are parsed but never included in the instantiated bounds. Temporary geometry is disposed after measurement.

The official [3MF Core Specification v1.3.0](https://3mf.io/spec/core-v1-3-0/) confirms row-major affine transform attributes, a default unit of millimeter when omitted, the valid unit set (`micron`, `millimeter`, `centimeter`, `inch`, `foot`, `meter`), and that only build-referenced objects are output. `get3mfUnitScale` centralizes the factors. The bounds are converted to millimeters once after transformation and bounds calculation.

Scan results persist the full versioned measurement JSON. Old bare-dimensions rows are scheduled for metadata enrichment even when mtime and size are unchanged. A metadata-only update writes dimensions/counts; it does not clear thumbnails, tags, notes, or print status. Existing consumers remain untouched here; U06 should use `toMeasurementPresentation` so old unversioned rows are visibly unverified and unavailable rows show their reason.
