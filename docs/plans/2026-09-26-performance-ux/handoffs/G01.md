## Integrated journey

`tests/product/e2e/integrated-library.e2e.ts` creates an isolated app and scratch library with 80 physical STL/OBJ records and a real 520-member ZIP. It scans 600 models, annotates all rows, creates a 600-path collection, uses the visible UI to sort/search and scroll/select collection record 501, pages the collection and archive, tags and compares models, previews an archive member, exports more than 500 annotations, previews an import with one pending, one unmatched, and one conflicting entry, then applies it. The test verifies the 600-model count, all 600 file IDs/paths/content revisions, and all seeded annotations after import.

`tests/product/e2e/thumbnail-clear-race.e2e.ts` holds a valid rendered thumbnail PNG in the main-process result handler after decode and before cache write. It clears the cache while the result is held, then releases the handler. An isolated-only marker reports success only after the cache identity/epoch guard rejects the stale response and temporary/final file cleanup succeeds. The test checks the cancellation result, absence of stale output and DB reference, successful alternate-color regeneration, and a later manual regeneration in the original color. The hook requires `POLYTRAY_ISOLATED_TEST=1`, a realpathed exact target under `POLYTRAY_PERF_SCRATCH`, and regular nonsymlink hold/release markers in scratch. Outside isolated mode the normal execution path does not await the hook.
