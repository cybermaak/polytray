# F02 handoff: portable fixtures and diagnostics

## Delivered

- Added deterministic in-process SQLite fixtures at 600, 10k, and 50k rows using the application migrations, with 40 directories, multiple extensions, deliberate sort ties, a full collection, and a last-only collection.
- Added generated, temporary STL/OBJ/3MF fixtures covering malformed files, a dense single mesh, multipart geometry, units, component and scaled build transforms, unsupported materials, external components, 501 archive entries, and controlled file revisions. The routine parser test uses 20k triangles; the diagnostics script creates 200k.
- Added independent barriers for subtree discovery, directory failure, parsing, extraction, and cancellation. Barriers can be released in a chosen order without sleeps and clean up abort listeners.
- Added isolated Electron launch with private user-data and scratch directories, before-launch fixture seeding, `ELECTRON_RUN_AS_NODE` stripping through the shared launcher helper, and a mock native launcher for slicer tests.
- Added separate main heartbeat, renderer long-task, explicitly marked viewer-frame, first committed batch, and preview phase probes. The renderer probe schedules no animation frames; draw calls are never labeled as frames.
- Added a developer baseline harness for the real Electron `GET_FILES` folder path and a 200k STL parser diagnostic. It is not included in default product tests.

## Limits

- The synthetic database query excludes archive-summary grouping; the separate archive fixture verifies a ZIP with more than one page of STL entries.
- Runtime query timings vary by machine and are reference observations, not CI thresholds.
- No production test hooks or source-service changes were introduced.
