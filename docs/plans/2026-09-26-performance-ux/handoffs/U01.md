# U01 handoff: complete library paging and selection

## Implemented in the current worktree

- Added a revision-aware paging reducer/hook with stale-generation rejection, stable-key append deduplication, retryable page errors, same-scope loaded-range refresh, interrupted-offset retry after stale-page refresh, and refresh-loop cancellation on query change, disable, and unmount.
- App uses `getLibraryPage` with collection membership in the query. It no longer filters or groups page results in the renderer. The legacy reader remains a temporary startup fallback until the first page succeeds or errors.
- The virtualized grid uses stable library-item keys, `endReached`, loading/error/retry state, and server-backed item/model totals. Same-scope refresh preserves loaded rows until the replacement range is ready.
- Selection retains real `FileRecord`s by ID across page appends, updates them after mutations, removes confirmed deletions from batch and comparison state, and clears on query-scope changes with a polite announcement. Archive summary rows have no file ID and cannot enter batch operations.
- Grid/archive/compare thumbnails use T03 `ThumbnailImage` with content revision identity. Ready events invalidate the cache path before patching the current record.
- App subscribes to the frozen T02 invalidation API. It evicts all or selected cache paths before clearing thumbnail references in loaded page items, selection, legacy fallback, and active preview target; this path does not reset pages or refresh the list.
- `ThumbnailReadyPatch` follows the current main event shape `{fileId, thumbnailPath, identity, contentRevision}` and matches identity path/revision before patching. This U01 base still has the older two-field preload callback type; the App casts only that callback boundary until latest main is merged.
- Added a 600-record fixture seed and `library-pages.e2e.ts` for collection record 600, empty collections, page-boundary ties, retained selection/batch tagging, grouped 520-member archive counts, archive-scoped tail paging, and a real thumbnail arrival/invalidation flow.
