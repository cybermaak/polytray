# U01 handoff: complete library paging and selection

## Implementation

- Added the revision-aware page reducer and hook with immutable query snapshots, generation/scope/unmount guards, stable-key dedupe, same-scope refresh, retryable page errors, and automatic retry of the interrupted offset after a stale next-page response.
- App and FileGrid now use SQL-backed library pages. Collection membership is part of the query; archive grouping and model totals are server-backed. The grid preserves selection across page appends, updates current file rows on metadata changes, and removes confirmed deletions from page, batch-selection, and compare state.
- The U01 App creates `PreviewTarget` values with the originating `LibraryQuery` for archive previews and passes the target to V02. The shared T02 invalidation event evicts thumbnail cache paths before clearing matching renderer references. Thumbnail-ready patches use `ThumbnailReadyData` and reject path/content-revision mismatches.
- `preferCurrentFileRevision` protects loaded page rows, archive samples, selected/legacy/comparison rows, and preview targets from late updates carrying an older content revision.
- The 600-record E2E covers collection record 600, stable page-boundary ties, empty collections, retained cross-page selection/batch tags, grouped 520-member archive counts, archive-scoped tail paging, and thumbnail arrival/invalidation while retaining browse position.
