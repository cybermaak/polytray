## Query behavior

`getLibraryPage(db, query)` implements the frozen `LibraryQuery` and `LibraryPageResult` contract. Filters (indexed scope, extension, literal name/tag search, collection, and optional archive identity) run in SQLite before paging. Counts, grouping, stable ordering, page selection, and archive thumbnail samples share one read snapshot. ZIP member identity remains opaque; only scope keys are canonicalized. Complete archive summaries expose at most four sample records and no unbounded member arrays. Collection membership uses a request-local temporary table with bounded 500-path inserts. A stale expected browse revision returns `{ status: "stale", revision }`.

`getLibraryFiles` preserves the legacy GET_FILES response/defaults. Once the scope index is ready, it uses SQL scope membership and SQL ordering; while the bounded D01 backfill is incomplete, GET_FILES retains its existing reader. The new IPC reader waits for injected bounded scope readiness before returning any indexed result.
