## Scan adapter contract

`registerScanningHandlers(...)` returns `{ scanJobs, dispose }`. `scanJobs` implements the shared `ScanJobs` contract from `src/shared/backgroundJobs.ts`:

- `getBackgroundJobs(): Promise<BackgroundJob[]>`
- `onBackgroundJobChanged(callback): () => void`
- `pauseJob(jobId)`, `resumeJob(jobId)`, `cancelJob(jobId)`, and `retryJobFailures(jobId)`, each returning `Promise<BackgroundJobCommandResult>`

`BackgroundJobCommandResult` is either `{ ok: true, jobId, state }` or `{ ok: false, reason }`, where reason is `not-found`, `invalid-state`, or `no-retryable-failures`. A repeated pause on a paused job, resume on a running job, or cancel on a cancelling/cancelled job succeeds idempotently. Resume is valid only from paused; retry is valid only from partial/failed with retryable failures. Route generic commands by `job.kind`, as the coordinator owns those IPC channels. The scanning module continues to publish the combined job feed; do not duplicate the generic router there.

Pause resolves only after the current discovery event/index batch settles and active metadata extraction drains. The producer waits before requesting the next discovery event. Resume releases that same scan and retains its coverage snapshot. Cancel aborts the discovery signal and metadata requests, drops queued metadata/discovery work, and bypasses pruning. The existing thumbnail queue is not started for cancelled scans.

Retry uses stored file/scope errors only. Metadata failures re-enrich the failed path using its current indexed content revision. An `ARCHIVE_FAILED` retries that archive alone through `streamDiscoverArchive`; the archive virtual root limits index/prune snapshots to its members. Other discovery failures retry their exact directory scope. Healthy sibling paths are not enumerated by archive retry. Terminal history is newest-first and capped at 20 jobs.

Scanning does not enable or modify watching. The renderer's existing watch setting remains authoritative. No watch-start hook was added to the scan completion path.
