# U02 implementation handoff

## Scope

U02 is implemented on top of `12ba102`. App owns both the visible search draft and the applied query; Toolbar is controlled by App. The existing 200 ms typing delay remains. Its effect cleanup cancels the pending commit when the draft changes, the applied query is externally reset, or Toolbar unmounts. Clearing the field or dismissing the search chip clears both values immediately.

List refreshes now request only pages, stats, or directory topology selected by a typed refresh target. Mutation events coalesce target flags over the existing 150 ms delay: row changes refresh pages, stats changes refresh stats, topology changes refresh directories, and annotation changes refresh pages only while search can match tags. Annotation updates still patch selected/comparison records directly. `onFilesUpdated` refreshes pages only. Required reads start concurrently.

`useLibraryPages` already preserves loaded rows during same-scope refresh and fences obsolete query generations; those behaviors were left intact. Its existing tests cover late query results and same-scope atomic replacement.
