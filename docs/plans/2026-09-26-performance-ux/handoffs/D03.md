## Behavior

- `src/main/librarySummary.ts` exposes `getStats()` and `getDirectories()` through one per-database WeakMap service. Stats are computed by one aggregate SQL read and cached against durable `statsRevision`; directories are read once per `topologyRevision`. Both caches check durable revisions on each request, so cached values cannot remain stale after committed repository writes. Directory results reuse the prior array reference when a revision changes but the sorted directory set does not.
- Existing `GET_STATS` and `GET_DIRECTORIES` IPC handlers now use the summary service. No new IPC/preload surface was needed.
- File-index mutation flags now invalidate stats only for insertion/deletion, size changes, or extension changes. Same-size timestamp/content revisions do not recount global totals. Annotation edits and metadata enrichment still advance browse revision but do not advance stats or topology revisions. Vertex/face/dimensions enrichment no longer signals stats changes. Directory changes still invalidate topology; thumbnail-only writes do not advance any summary revision.
- Empty-library aggregate results preserve the legacy all-zero stats shape.
