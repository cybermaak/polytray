# U03 handoff: responsive panel layout

## Changes

- Added a pure layout calculation that preserves a 400px browse area, docks the preview only when the 320px minimum fits, and clamps the effective sidebar width on narrow windows while retaining saved preference widths.
- Added `sidebarWidth` and `previewWidth` to the existing normalized AppSettings payload. Defaults are 260px and 360px; normalized preference bounds are 200–600px and 320–900px.
- Made Sidebar and PreviewPanel use App-controlled preferred/effective widths. Narrow preview uses an absolute overlay over the content region, so the grid retains its layout and state. Explicit expanded mode remains independent.
- ResizeObserver now calls viewer resize invalidation only when the visible viewer container's integer dimensions change.
- Added panel/settings unit coverage and a product E2E matrix for 900x600, 1280x800, and 1920x1080; default/minimum/maximum saved widths; dark/light themes; long names; screenshot attachments; browse-width bounds; persistence; expanded mode; batch selection; and scroll preservation.
