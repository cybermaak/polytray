## Format decisions

The version-1 JSON document contains `format`, `version`, `exportedAt`, `appVersion`, `annotations`, `pendingAnnotations`, `collections`, `libraryRoots`, `preferences`, and a `manifest`. The manifest states that the backup is metadata-only and source model files are not included. The required `pendingAnnotations` array is separate from indexed `annotations`; each is unique by canonical path. An indexed annotation and a pending annotation may share a path, preserving different notes/status without export-time merging. Duplicate records within one source union normalized tags only when their notes and statuses agree; conflicting duplicate notes/statuses fail explicitly.

Physical paths use `path.resolve`. Archive-backed paths use `parseArchiveEntryPath`/`createArchiveEntryPath` so the resolved archive path and normalized virtual member remain distinct. Path spelling inside actual file names is retained. Roots and collection members are canonicalized and deduplicated. Collections and roots come from the caller's normalized renderer snapshot; no page query or second state store is introduced. Preferences use the existing settings normalizer, but only explicitly supplied portable fields are emitted. Operational scan timings, page size, cache paths, model metadata/bytes, SQLite IDs, and executable settings are omitted.

## Implementation and evidence

The main service reads annotation rows in one synchronous SQLite transaction before opening the save dialog, with no SQLite transaction held across an await. The revision provider is checked before dialog preparation, after the dialog resolves, and immediately before atomic rename. Pending records arrive through an explicit optional provider; P04 owns their persistence/source.

The default writer creates a mode-0600 temporary file in the chosen target directory, writes and syncs it, checks the renderer revision, then renames it over the target. Cancellation does not write. Errors clean up the temporary file and leave the previous target in place. The service reports location plus indexed annotation, collection, and pending annotation counts.

Red-to-green regressions were added for unsupported/malformed input, archive paths, overlapping indexed/pending records, Unicode notes, all 510 indexed rows (including collection membership for row 510), portable-field exclusion, native dialog cancellation, renderer revision changes while the dialog is open and before rename, write failure, and export-only IPC runtime validation. SQLite fixtures use in-process `better-sqlite3`; tests use temporary directories and injected dialogs/writers.
