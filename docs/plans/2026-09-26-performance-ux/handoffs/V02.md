# V02 handoff: durable preview state and archive paging

## Implementation

- `PreviewPanel` now consumes `PreviewTarget` and the originating `LibraryQuery`; App forwards archive targets directly while preserving the regular-file preview path.
- Geometry loads use a stable identity containing file ID, path, extension, and content revision. Annotation and thumbnail updates patch current records without changing geometry identity, camera state, or the active viewer session.
- Preview loading/error/retry state is keyed by identity and load token. Failed parses remain visible and retryable; stale completion cannot replace a newer selection.
- Archive members load lazily in 24-item pages. Navigation carries forward the originating filters, bounds page cache, refreshes on browse-revision changes, retains the selected member path, and fences thumbnail arrivals by file ID/content revision.
- `#viewer-error` is contained to `.viewer-stage`, so a failed archive member remains readable/retryable without intercepting archive navigation controls.
