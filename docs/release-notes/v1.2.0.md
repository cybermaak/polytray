# Polytray v1.2.0

This release makes large local model libraries more complete to browse, safer to
maintain and easier to control. It adds background job controls, portable metadata
backup and restore, and explicit handoff to a local slicer.

## New workflows

- **Background job controls:** inspect scan and thumbnail progress, pause or resume
  supported jobs, cancel unfinished work, retry failures and dismiss finished jobs.
  Discovery, indexing and thumbnail completion have separate progress indicators.
- **Metadata backup and restore:** export annotations, collections, library roots
  and supported preferences to a portable JSON file. Preview imports and conflicts
  before applying them. Unmatched annotations remain pending for later matching.
  Restore uses a recovery journal to complete interrupted committed changes.
- **Local slicer handoff:** choose a local slicer or explicitly use the system
  default. Open a selected supported model or an individual ZIP member, with clear
  preparation and failure states.

## Library browsing and scanning

- Browse matching models beyond the previous first-page limit. Filtering, sorting,
  collections, counts and archive grouping operate across the indexed library.
- Preserve browsing position while scans add records, and avoid unnecessary
  refreshes for unrelated thumbnail or annotation updates.
- Show useful indexed results before a folder scan finishes. Metadata extraction
  runs in a dedicated background process with bounded queues.
- Retain indexed records when roots, subfolders or archives are unavailable.
  Cancelling a scan keeps completed work and does not prune unseen files.
- Reject stale scan and watcher updates so obsolete work cannot overwrite newer
  file records or restore a removed record.

## Thumbnails, previews and usability

- Publish completed thumbnails progressively, regenerate missing cached images
  and prevent outdated work from undoing a cache refresh or clear.
- Give 3MF parsing a separate disposable renderer and transfer prepared geometry
  through a dedicated bridge. Improve cancellation and resource cleanup, including
  Linux preview-renderer shutdown.
- Keep model geometry and the camera stable when annotations change. Render on
  demand after interaction settles and pause viewer activity while minimized.
- Improve measurement accuracy and labels: supported 3MF dimensions apply source
  units and transforms; STL/OBJ dimensions remain in model units.
- Improve small-window layouts, preview overlays, keyboard navigation across
  virtualized pages and focus recovery after closing overlays.

## Reliability

- Harden indexed-file access, ZIP reads, short-read handling and revision checks.
- Prevent Apply Import while a scan is active, paused or retrying, including raced
  requests at the main-process boundary.
- Retry brief Windows file locks when replacing restore journal records while
  continuing to surface unrecoverable errors.
- Improve isolated test fixtures, native-module rebuild sequencing and platform
  CI coverage. The existing macOS signing/notarization process remains supported.

## Notes and current limits

- Metadata backups contain metadata, not source model files or thumbnail images.
  Restoring library roots does not automatically scan or watch them.
- SQLite operations still run in the main process; large scans or imports can
  briefly affect responsiveness. Moving database work to an owned worker remains
  planned work. This release does not claim that all performance targets are met.
- File-access hardening does not eliminate every hostile concurrent filesystem
  replacement race.
- Collections, tagging, comparison, ZIP browsing and dimensions were already
  available in v1.1.1; this release improves those existing workflows.
